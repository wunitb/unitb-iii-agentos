# Function ids the engine's own workers register on a credential-less session.
#
# Captured from a LIVE armed boot, not written by hand. Every id here was seen by
# `agentos::bus_on_register` with `context.agentosBusTier = "untrusted"`, i.e. it
# is a registration the bus policy must admit or the shipped stack loses that
# function. The first version of UNTRUSTED_REGISTRATION_PREFIXES held worker
# names instead of id namespaces and refused 107 of these; the stack came up with
# 36 functions and no LLM routing at all.
#
# Regenerate (iii 0.22.1, ~40 s):
#   1. cargo +1.90 build -p agentos-bus-auth
#   2. AGENTOS_API_KEY=<key> RUST_LOG=debug agentos-bus-authd --listen=127.0.0.1:49129
#   3. boot `iii` with this repo's config.yaml plus the rbac + iii-bridge block
#      from /tmp/agentos-remediation/requests/bus-rbac.md (do NOT set
#      IIIWORKER_DISABLE_BUILTIN_DAEMONS: `worker::*` comes from iii-worker-ops)
#   4. grep the daemon log:
#        sed -n 's/.*allowed function registration function_id=\([^ ]*\).*/\1/p' \
#          authd.log | sort -u
#      and confirm `refused function registration` never appears.
#
# Captured 2026-09-02 · engine 0.22.1 · workers as pinned in iii.lock
